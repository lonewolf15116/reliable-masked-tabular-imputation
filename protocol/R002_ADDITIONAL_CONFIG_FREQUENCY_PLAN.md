## Fixed fallback defect alternative — preregistration clarification

**Runtime and sample size were already fixed:** 120 seconds per feature for the primary 60,000 draws; if exceeded, declare INCOMPLETE, then use an independent precommitted 10,000-draw fallback only. The previous successful Review Candidate 005 60,000-draw experiment is immutable and **not subject to this fallback**.

For each newly approved toy-enumerable category distribution `P` (all k-subset masks sorted lexicographically), the preregistered *power defect alternative* `Q` is constructed as follows. Let `a` be the lexicographically first category with maximum probability and `b` the lexicographically first category with minimum probability, `a != b`. Set `Q[a]=P[a]-0.01`, `Q[b]=P[b]+0.01`, with all other categories unchanged. If `P[a]<0.01` the defect alternative cannot be constructed and the fallback is **INCONCLUSIVE** (never silently reduce the defect size). The 0.01 is an **absolute probability-mass shift of one percentage point**, not a relative 1% increase. This alternative detects a specific one-category redistribution defect; adequate power against it does not imply power against all possible implementation faults.

Power is estimated **before any fallback sampling**, using 10,000 independently seeded simulated datasets, each of size 10,000 from `Q`; enumerate `P` beforehand. Apply the exact preregistered goodness-of-fit test (Pearson if every expected count >=5; otherwise the 200,000-null-replicate Monte Carlo reference) at alpha=0.01. Freeze the power simulation RNG seed `440271` and hash the category distribution and simulation configuration/results before running any observed fallback draws. If estimated rejection power is **<80%**, or the power simulation cannot be completed, the 10k fallback is **INCONCLUSIVE**, not a PASS, even if the observed chi-square does not reject. This is a prospective plan and no new sampling or power calculations have yet been executed.
