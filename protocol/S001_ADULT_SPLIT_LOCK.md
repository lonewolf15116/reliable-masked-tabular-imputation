2. Parse ONLY the final comma-separated field to obtain the stratification labels, trimming surrounding spaces from that label. These labels are NOT imputation predictors and are never masked. No feature whitespace normalization, encoding, imputation or scaling is applied to determine split assignment.
3. Use `sklearn.model_selection.train_test_split` on the integer index vector `np.arange(1,32562,dtype=np.int64)`: first `train_test_split(indices, test_size=0.30, random_state=20261107, shuffle=True, stratify=income_stripped)` giving 70% train and 30% temporary; then `train_test_split(temp_indices, test_size=0.50, random_state=20261107, shuffle=True, stratify=temp_income_stripped)` giving 15% validation and 15% test. Same split seed is deliberately reused within the **split class** for those two calls, and no other seed class uses it.
4. Runtime contract: **CPython 3.12.x, NumPy 2.1.3, scikit-learn 1.5.2**. Reject other major/minor Python and different exact library versions rather than assuming bitwise reproducibility. The implementation script prints and records full patch-level Python version, sklearn version, NumPy version, and call signatures in the manifest. No Python built-in `hash()` is used.
5. For every split, sort row IDs ascending **only for serialization** (not for redefining the sampling law), and write one 1-indexed integer per line to `artifacts/splits/adult_{train|validation|test}_indices.txt` in UTF-8 with LF line endings. An independent verify-only mode must regenerate in memory from the original raw bytes and compare the exact byte strings and all hashes. Verify no duplicate indices, complete 1..32561 coverage and no index overlap.

7. Near-constants with IQR >0 remain included. No eligible-cell manifest may be finalized before this step; all methods must use identical masked eligible cell IDs.
